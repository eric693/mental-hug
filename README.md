## 這套系統跟一般客戶管理系統的差別

心理諮商的核心限制是**保密**。系統把「行政資料」與「晤談內容」分成兩層：

| 資料層 | 誰看得到 |
|---|---|
| 個案基本資料、預約、收費、同意書 | 行政櫃檯、心理師、督導、管理者 |
| 晤談紀錄（SOAP）、處遇計畫 | **僅主責心理師本人、督導、管理者** |
| 危機事件與通報 | 心理師、督導、管理者（行政預設無權限） |

- 保密邊界由 `src/auth.js` 的 `canViewNote` / `canViewClientNotes` / `requireNoteAccess` 統一把關，
  所有讀取晤談內容的 API 都必須經過它，不是靠前端隱藏按鈕。
- 每次調閱晤談紀錄都寫入稽核軌跡（誰、何時、看了哪位個案），管理者可於「稽核軌跡」頁查詢。
- 個案端**完全不提供**任何晤談紀錄內容，只做預約、改期、取消、量表、費用、同意書與行政訊息；
  逾免收費期限的取消只會送出「取消申請」並通知櫃檯，是否計費由櫃檯決定，個案端不能自行改變收費結果。

## 功能

**每日作業**
- 總覽：今日晤談、待補紀錄、高風險個案、量表警示、處遇計畫到期、待處理來電、明日待提醒、執照與契約到期
- 我的工作台（心理師個人視角）：我的個案與高風險數、本週排程（含視訊連結）、本月／今年服務量、
  待補紀錄與待完成衡鑑報告、個案未讀訊息與待填量表、追蹤中危機事件、本月開立費用，
  以及督導時數、繼續教育積分（總積分／特定三類／專業倫理分開檢核）與執照更新倒數
- 預約排程：週檢視（含團體場次與請假）；同一心理師或同一諮商室時段衝突即時擋下；可預約時段（weekday × 時段）設定
- 行事曆：月檢視一次看完晤談、團體場次與請假，可依心理師篩選；點任一天看當日明細並直接排約
- 我的排班：心理師自己在星期 × 時段格子上點選／拖曳刷出每週可預約時段，一次存檔（管理者可代設定），
  同頁登錄請假；排班存好後櫃檯下訂與個案端預約只會看到這些時段。
  **表格起訖時間、每格分鐘數與快填按鈕皆為系統設定**（各所作息不同）；
  不在格線上的時間（如 13:15-14:05）用「自訂時段」另行加入，可一次套用到多個星期
- 行事曆訂閱（.ics）：每位心理師一組 token 網址，可加入 Google／iPhone 日曆訂閱未來半年班表；
  **只帶個案編號不帶姓名**，網址可隨時重設讓舊訂閱失效
- 候補遞補：取消或未到釋出時段時，立即依「指定心理師 → 緊急度 → 希望時段吻合 → 等候天數」
  配對候補名單並可一鍵發送遞補通知（未設發送通道時只產生文字）；「候補遞補」頁列出所有仍空著的釋出時段
- 線上視訊晤談：形式選「視訊」即帶入該心理師的固定會議室連結（帳號設定），也可逐筆指定；
  連結只收 http(s)，自動附在晤談提醒訊息中，個案於專區與心理師於今日看板皆可一鍵進入
- 今日看板：報到／完成／未到／取消一鍵處理；完成時自動扣方案次數或產生收費單，未到依比例計費
- 晤談提醒：產生明日晤談的提醒文字供複製；填入 webhook 後可由系統直接發送簡訊／LINE（單筆或整批），
  每則發送皆留紀錄含失敗原因。未設定通道時只產生文字供人工發送，不把個資送到外部服務
- 待補晤談紀錄：已完成但未寫紀錄者，逾所內規定天數以紅字標示
- **LINE 傳話與改期簽核**：個案在官方帳號傳「改期／請假」（關鍵字可設定）→ 系統抓出他最近一筆有效預約，
  把原話轉到該心理師的 LINE 群組並自動回覆個案已收到 → 心理師在群組回覆（多筆同時進行時寫 `#編號` 指定），
  內容自動記入申請單 → 行政人員在「改期簽核」頁填新時段簽核，**檢查心理師與諮商室衝突後才真正改期**，
  同時把新時間送回個案對話框與心理師群組。心理師沒回時行政可電話問完「代錄回覆」；
  webhook 以 channel secret 驗簽章，憑證未填時一律拒收且不對外送任何訊息，流程仍可在系統內跑完。
  個案以「綁定 手機號碼」對應身分，非改期類訊息只進「個案訊息」不打擾心理師群組

**總覽**
- 儀表板長條圖：近 6 個月完成晤談（滑鼠移上顯示當月未到次數）、近 6 個月實收金額、近 6 個月新收個案、
  本月各心理師完成晤談；另有「可遞補時段」與「個案端取消申請」待辦區塊

**個案服務**
- 來電登記與派案：來電 →（候補）→ 派案 → 初談建檔的完整漏斗，高風險來電標紅、等候天數超過 14 天示警
- 個案端自填初談問卷：產生免登入連結（有效天數可設定）以簡訊／LINE 傳給來電者，
  填寫基本資料、主訴、就醫史與 BSRS-5；建檔時聯絡資料與主訴一併帶入、量表轉為療效追蹤基線，
  命中自殺意念題自動標為高風險並拉高來電緊急度。尚未登記來電也可先發問卷，填完一鍵轉為來電登記
- 團體諮商：團體、成員名單、場次排程、出席點名、團體歷程紀錄（僅帶領者可讀）、出席自動計費
- 個案管理：編號自動產生（C+年份+流水）、身分證統一編號（含檢查碼驗證）、主責心理師、風險等級、
  依生日自動判定未成年（民法 18 歲，門檻可設定）、法定代理人欄位、結案摘要（可列印）
- 個案附件：轉介單、診斷證明、同意書掃描、衡鑑報告上傳（PDF／圖片／Office，單檔 20MB）；
  隨機檔名落地、目錄不對外開放、下載逐次驗權並記入稽核；可逐檔開放個案端下載
- 晤談紀錄：SOAP 格式 + 使用技術、家庭作業、風險標記；簽核定稿後比照病歷不可修改
- 實習心理師督導覆核：帳號可標記為實習生並指定督導；實習生的紀錄按「送督導覆核」後
  **不會直接定稿**，送出期間不可修改，由指定督導（或督導／管理者）覆核通過才鎖定，
  或填意見退回補正（修改後需重送）。「紀錄覆核」頁列出待覆核與被退回的紀錄，逾期未覆核紅字標示
- 安全計畫（Safety Plan）：警訊、自我因應、可轉移注意力的人事地、可求助親友、專業協助、
  危機資源、環境安全、值得活下去的理由共 8 段；**可列印一份給個案帶走**（含簽名欄）；
  內容更新以新版本保存、舊版可查；保密層級同晤談紀錄。
  「安全計畫列管」頁盯高風險個案是否都有現行計畫、是否逾預定檢視日，總覽與我的工作台皆有警示
- 處遇計畫：治療取向、個案概念化、多筆目標與進度條、預定檢視日提醒
- 心理衡鑑報告書：轉介問題、施測工具、背景資料、行為觀察、分數摘要表、綜合印象與建議；
  保密層級同晤談紀錄，簽核定稿後不可修改，可列印（抬頭帶所別資訊、落款帶證照字號）；
  已完成的心理衡鑑晤談若尚未產出報告，會列入「待補紀錄與報告」頁列管
- 心理量表：PHQ-9、GAD-7、BSRS-5（心情溫度計）、PSS-10、ISI，內建計分與切分點判讀；
  同一量表多次施測畫成折線圖（含判讀切分點與危險題標示），個案頁、處遇計畫頁與個案端皆可看；
  PHQ-9 第 9 題／BSRS-5 附加題命中即自動拉高風險等級並列入總覽警示
- 危機事件：類型、嚴重度、已採取處置、法定通報管道與案號、後續追蹤與結案；
  責任通報類型自動帶出 24 小時通報期限（類型與時限可設定），逾時未通報紅字警示並可篩選；
  **責任通報表套印**：把當事人、法代、事件概要、已採處置、通報人與單位資訊帶成一張可列印的表，
  供抄錄或附件用（實際通報仍走 113／關懷 e 起來等主管機關管道，完成後回填時間與案號）
- 轉介與結案後追蹤：轉出／轉入紀錄（對象、原因、對方是否接案與回覆時間），
  結案時依設定自動建立追蹤點（預設 30、90 天），「結案追蹤」頁列出到期與逾期者，
  完成追蹤須填結果；保密層級同晤談紀錄
- 同意書：知情同意、未成年法代同意、個資告知、錄音錄影、緊急聯絡共 5 份範本；
  手寫簽名、簽署當下全文快照；範本改版自動遞增版本，已簽者需重簽

**專業與營運**
- 督導紀錄：個督／團督／同儕，年度時數統計對照目標時數
- 請假與繼續教育：請假期間自動從可預約時段移除並擋下櫃檯下訂；繼續教育積分依執照更新週期彙總
  （特定三類合計下限與專業倫理個別下限分開檢核）與執照到期倒數
- 報酬與扣繳：心理師鐘點給付單，依設定費率試算代扣所得稅與二代健保補充保費（可人工覆寫）；
  可依當月已完成晤談批次帶入；年度依所得人與所得類別彙總，供填報扣繳憑單
- 合作單位與請款：學校認輔、企業 EAP、社政委託案的契約額度追蹤，按月彙整產生對帳單／請款單（對帳單以個案編號列示，不記載姓名）
- 收費與方案：預付堂數方案（售出即產生收費單）、單次收費、收據號、付款人別（自費／EAP／學校／社會局）
- 逾期催繳：未收款超過設定天數者列管，含帳齡分析（30／60／90 天級距）、依付款人別與主責心理師篩選、
  催繳訊息範本、單筆或整批發送（未設定發送通道時只產生文字供人工發送），每則留發送紀錄
- 電子發票與補助核銷：發票號碼與日期、買受人統編（8 碼檢核）、抬頭、載具、捐贈碼；
  政府補助方案可記方案序號、補助額與自付差額（自動拆算）。已收款者仍可補登發票欄位，金額鎖住
- 個案訊息：行政聯繫用聊天串（改期、繳費），與晤談內容分離
- 退費：已收款項需退還時另立退費單與原收費單勾稽（不動原單金額），全額退還才把原單標為已退費；
  方案退費可依剩餘堂數試算並同步停止扣次，收費頁與報表以「收款 − 退費」計算實收，誤開可撤銷
- 公告、統計報表（服務量、來源、收入、合作單位、團體、危機事件、量表施測）
- 經營品質指標：爽約率、取消率、初談轉銜率、脫落率（逾 60 天未再晤談且無後續預約）、
  平均晤談次數，以及**心理師時段利用率**（實際完成時數 ÷ 排班開放時數）；分母為 0 時顯示「—」不顯示 0%
- 報表匯出：個案清單、晤談明細、收費明細、心理師服務量、危機事件，每份皆可出
  **Excel（.xls）／PDF（列印版）／CSV（含 BOM）**；匯出記入稽核軌跡
- 收據列印、對帳單列印；**期間彙總收據**（報稅／保險理賠／公司補助核銷用，列出期間內已收款項目與退費淨額）
- **諮商紀錄列印版**：SOAP 全文加機構抬頭、心理師證照字號與簽章欄，供轉介或法定用途；
  權限同線上調閱（主責心理師／督導／管理者），每次列印一樣寫入稽核軌跡

**系統**
- **模組啟用**：所方用不到的模組（如合作單位請款、危機通報、督導紀錄）於系統設定整組關閉——
  側欄不出現、API 一律 403，帳號的權限勾選保留不動，重新勾回即回復。
  預約排程、個案管理、晤談紀錄、帳號權限、系統設定為核心，不提供關閉。
  另有「繼續教育積分」細項開關（關閉後「請假與繼續教育」頁只留請假）
- 帳號權限：20 個模組逐一勾選；角色預設值（行政不含晤談紀錄與危機事件）；不可停用最後一位管理者；
  停用心理師時提示尚有幾筆未來預約與主責個案待改派
- 系統設定：所別資訊（含開業執照字號、負責心理師、機構統編）、收費預設、責任通報時限、
  扣繳費率、提醒發送通道、選項清單、前台文字、諮商室、同意書範本、
  排班表格線與快填、安全計畫檢視週期與危機資源、實習生覆核期限、個案端預約／改期開關、
  LINE 傳話機器人（channel secret／access token、預設群組、關鍵字與各段訊息範本）
- 舊資料匯入：個案名冊、晤談排程、收費明細、量表施測四種 Excel／CSV 匯入；
  下載範本 → 上傳預覽（完全不寫入）→ 確認匯入，逐列驗證且有任一列錯誤即整批拒絕；
  可選擇略過或更新既有資料，檔案只在記憶體處理不落地，匯入結果記入稽核
- 紀錄保存與歸檔：結案滿保存年限（預設 7 年）的個案清單，系統只提示不自動刪除
- 稽核軌跡、每日自動備份（保留 14 份 + `/root/backups/mental-hug` 異地鏡像，**個案附件一併同步**）；
  備份後 WAL checkpoint 回收空間，並清理無對應紀錄的孤兒附件檔

## 技術

- 後端：Node.js + Express 5 + better-sqlite3（WAL），JWT HttpOnly Cookie
- 前端：原生 SPA（無框架），共用 `public/css/style.css`
- 資料庫：`data/mindcare.db`，schema 見 `db/schema.sql`；新增欄位在 `src/db.js` 的 `ensureColumns` 補遷移

## 常用指令

```bash
npm start              # 直接啟動（預設埠 3350）
npm run seed           # 建立展示資料（已有個案時不重複灌入）
npm run smoke          # API 冒煙測試（拋棄式資料庫，不碰正式資料）
npm run smoke:ui       # 前端冒煙：無頭瀏覽器巡過所有頁面抓 JS 錯誤（需執行中的伺服器）
npm run deploy         # 上線流程：API 冒煙 → 備份 → pm2 重啟 → 前端冒煙（任一步失敗即中止）
pm2 restart mental-hug # 正式環境重啟（單獨重啟時建議改用 npm run deploy）
```

改完程式、重啟正式站之前先跑 `npm run smoke`：它會自己起一個測試用伺服器（隨機空閒埠），
以 `MINDCARE_DATA_DIR` / `MINDCARE_UPLOAD_DIR` / `MINDCARE_BACKUP_MIRROR` 指向暫存目錄，
完全不動 `data/mindcare.db` 與 `uploads/`；任一項失敗即 exit 1。
涵蓋登入權限、排班與可預約時段、預約衝突、行事曆訂閱、個案端預約改期取消、候補遞補、
晤談紀錄保密與實習生督導覆核、諮商紀錄列印、安全計畫、收費與退費、期間彙總收據、
LINE 傳話與改期簽核（含 webhook 簽章驗證與整段轉達→回覆→簽核流程）、模組開關、
附件上傳下載、備份與附件異地同步、報表與稽核。
